## Overview

This project is a **BDD test automation framework** built with the native Playwright Test runner and `playwright-bdd`, developed and maintained by **Seven Seven Global Inc.**
It uses Gherkin feature files and TypeScript step definitions to deliver readable, stakeholder-friendly tests while retaining full Playwright tooling support (UI mode, trace viewer, sharding).

## Key Concepts

| Concept | Description |
|---|---|
| **SelfHealingLocator** | Wraps every element with 6 fallback strategies (data-testid → aria → placeholder → text → CSS → XPath). If the primary locator breaks, it tries the next strategy automatically and updates the registry. |
| **LocatorRegistry** | Persists the winning strategy for each element to `reports/locator-registry.json`. Promoted strategies become the new primary on the next run. |
| **test-fixtures.ts** | Central fixture registry. All Page Objects are registered here and injected into step definitions via `createBdd(test)` — no manual instantiation or CustomWorld needed. |
| **playwright-bdd** | Bridges Gherkin feature files and the Playwright test runner. `npx bddgen` compiles `.feature` + step definitions into `.features-gen/` Playwright test files that run with `npx playwright test`. |
| **Step ↔ Feature mapping** | Every step definition in `step-definitions/` corresponds to one or more Gherkin steps in `.feature` files, tagged with `@req-REQ-XXX` for full traceability. |

## Getting Started

1. Copy `.env.example` to `.env` and fill in your `BASE_URL` and test credentials.
2. Drop a BRD or user story file into `requirements/`.
3. Tell Claude: *"I added a requirements file to requirements/"*
4. Claude will analyse it (Phase 2) and generate a `.feature` file + update the master RTM.
5. Tell Claude: *"Generate scripts"* to produce Page Objects and step definitions (Phase 3).
6. Tell Claude: *"Run tests"* to execute and self-heal (Phase 4).

## CLI Command Reference

### Test File Generation (required before every run)

```bash
# Compile .feature + step definitions into Playwright test files in .features-gen/
npx bddgen
```

### Basic Execution

```bash
# Run all tests (bddgen + playwright test)
npm test

# Run a single feature or spec
npx bddgen && npx playwright test features/authentication/login.feature

# Run only tests scripted (@ready) — recommended default
npx bddgen && npx playwright test --grep "@ready"
```

### Filtering by Tag or Name

```bash
# By tag
npm run test:smoke                              # → --grep @smoke
npm run test:regression                         # → --grep @regression
npx bddgen && npx playwright test --grep "@ready"
npx bddgen && npx playwright test --grep "@req-REQ-026"

# By scenario name / TC-ID
npx bddgen && npx playwright test --grep "TC-056"
npx bddgen && npx playwright test --grep "successful login"

# Invert filter (skip WIP)
npx bddgen && npx playwright test --grep-invert "@wip"
```

### Browser Projects

```bash
npm run test:chromium                           # → --project=chromium
npm run test:firefox                            # → --project=firefox
npm run test:webkit                             # → --project=webkit
npx bddgen && npx playwright test --project=chromium --project=firefox
```

### Debugging & Interactive Modes

```bash
npm run test:headed                             # see the browser
npm run test:ui                                 # interactive UI mode (time-travel)
npm run test:debug                              # Playwright Inspector, step through
npx bddgen && npx playwright test --headed --slowmo=500
npx bddgen && npx playwright test --last-failed
npx bddgen && npx playwright test --repeat-each=3   # flakiness detection
```

### Reporting

```bash
npm run report:html                             # Playwright HTML report
npm run report:allure                           # generate + open Allure report
npx playwright show-trace test-results/<trace>.zip
```

### Type Checking & Linting

```bash
npm run typecheck                               # → tsc --noEmit
npm run lint                                    # → eslint src + step-definitions
```

### Self-Healing Utilities

```bash
npm run healing:report                          # print healed-locator summary
npm run healing:clear                           # reset reports/locator-registry.json
```

### Environment Overrides

```bash
BASE_URL=https://staging.example.com npm test
TEST_USER_EMAIL=ci@example.com TEST_USER_PASSWORD=CIPass123 npm test
```
